Supplier Performance Rating System - Full Stack

1. Create MySQL database: supplier_rating_db
2. Check backend/src/main/resources/application.properties for MySQL username/password.
3. Open backend in VS Code/IntelliJ.
4. Run: mvn spring-boot:run
5. Open: http://localhost:8080/
6. Register a user, then login.
7. Frontend now calls Spring Boot REST APIs instead of localStorage.

Password rule: minimum 8 characters, one uppercase letter, one number and one symbol.
